# ICHES Frontend Reference Register

**Workstream:** PF-00  
**Status:** ACTIVE REFERENCE BOUNDARY

This register records approved inspiration sources and explicitly limits how they may influence implementation.

## REF-PUB-001 — AICIS+

URL: https://aicis.uinssc.ac.id/

Role:

- conference-product reference;
- public information architecture reference;
- multilingual conference reference.

Approved inspiration:

- mature public conference information coverage;
- announcement patterns;
- conference theme presentation;
- important dates/timeline;
- tracks/sub-themes;
- conference process explanation;
- publication information;
- FAQ/news concepts;
- multilingual public experience.

Not approved for copying:

- branding;
- logos;
- text;
- media;
- exact layout;
- exact visual styling;
- source code.

## Reference rule

References guide principles, not duplication.

When a frontend decision cannot be traced to:

1. Product Blueprint / V1 requirements;
2. Frontend Product Specification;
3. this public frontend baseline;
4. an approved reference principle;

the implementation should stop and request a decision instead of inventing product policy.
