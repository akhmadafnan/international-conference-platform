# Project Charter

**ID:** ICP-GOV-CHARTER-001  
**Status:** DRAFT FOR PHASE 0 APPROVAL

## Purpose

Build a reusable multilingual academic conference lifecycle platform that is operationally simple for the first small event but structurally sound for recurring editions.

## Initial context

- approximately 100 participants/submissions;
- primarily Indonesian participants initially;
- limited committee/technical resources;
- conference may recur annually or biennially.

## Non-negotiable product principles

- multi-edition;
- `id/en/ar`;
- Arabic RTL;
- payment independent from academic acceptance;
- presented does not automatically mean publishable;
- OJS downstream;
- traceable consequential actions;
- no one-event disposable schema.

## Phase 0 success

Phase 0 is complete only when:
- PRD reaches accepted baseline;
- actors/lifecycle are documented;
- decision/requirement registers reconciled;
- major open questions resolved or explicitly deferred;
- integration/standards baseline exists;
- Definition of Ready for Phase 1 is approved.
